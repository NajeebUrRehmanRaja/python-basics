# Python Basics

Learn foundational Python through small, focused examples. Each folder contains short scripts that demonstrate core language features like variables, strings, collections, and dictionaries.

## Quick Start
- Requirement: `Python 3.10+` installed on your machine
- Run any example from the repo root:
  - Windows: `python <relative_path_to_script>` (use quotes for paths with spaces)
  - If `python` isn’t recognized, try `py <relative_path_to_script>`

## Topics & How to Run

### Variables and Strings
- Variables overview: `python VariablesInPython\variables-python.py`
- Adding variables: `python VariablesInPython\add-variables.py`
- Arrays (lists) length: `python VariablesInPython\array-length.py`
- String case methods: `python VariablesInPython\cases-string.py`
- Using `dir()` to inspect objects: `python VariablesInPython\dir-function.py`

### Variable Types
- Core Python types (int, float, str, bool, etc.):
  - `python PythonVariableTypes\PythonVariableTypes.py`

### Conditionals and Booleans
- If/elif/else statements and boolean logic:
  - `python "Conditionals and Booleans - If, Else, and Elif Statements\Conditionals and Booleans - If, Else, and Elif Statements.py"`

### Functions
- Defining functions, parameters, return values, and scope:
  - `python Functions\Functions.py`

### Import Modules and Standard Library
- Working with modules and exploring Python's standard library:
  - `python "Import Modules and Exploring The Standard Library\intro.py"`
  - Custom module example: `python "Import Modules and Exploring The Standard Library\my_module.py"`

### Loops and Iterations
- For loops, while loops, and iteration control:
  - `python "Loops and Iterations - For&While Loops\Loops and Iterations - For&While Loops.py"`

### Lists, Tuples, and Sets
- Working with common collections:
  - `python python---Lists-Tuples-and-Sets\python---Lists-Tuples-and-Sets.py`

### Dictionaries (Key–Value Pairs)
- Creating and using dictionaries:
  - `python "python-Dictionaries - Working with Key-Value Pairs\python-Dictionaries - Working with Key-Value Pairs.py"`

## Tips
- Run scripts from the repo root so the relative paths above work.
- Use quotes around paths with spaces (as shown in the Dictionaries example).
- Modify any script and re-run it to experiment with changes.
